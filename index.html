Features

Everything a modern developer needs.

No Electron. No subscriptions. Just a fast, focused native app.

AI Agents, natively

Bring your own AI coding agent — Claude Code, opencode, Codex, Gemini CLI, Aider, or any other CLI you add yourself — and it just works, already pointed at the right folder. Run several agent tabs side by side, no PATH to configure.

Worktree-first

Work on three branches at once, without losing your place. Start a new worktree from any branch in a click — each one gets its own agent, shell, files, and changes, and everything follows when you switch.

Review, then hand it back

The Changes tab updates live as your agent edits files. Read the diff, comment on any line, and send that note straight to the agent — no copy-pasting file paths and line numbers.

Prompts & commands, ⌘K away

Save the prompts and commands you reach for every day, per project or in a shared library. Press ⌘K, pick one, and it lands in your agent or a shell tab — ready to run.

Git, in plain English

One Sync button instead of fetch, pull, and push. Save your changes, see your recent saves, and if a pull is blocked by local edits, Grove offers to stash and pull for you.

Files, with real previews

Browse the checkout in a file tree and preview what you click. Markdown renders GitHub-style — tables, code, even Mermaid diagrams — and exports to PDF in one step.

Shell tabs

Need a real terminal? Open as many as you like, all rooted in the same folder as your agent — run the tests in one, tail a log in another, no context switch.

Your project's web pages, pinned

Pin the issue tracker, docs, or dashboard that goes with each project. They open in the Browser tab, right next to your code, and stay with that workspace.

No destructive defaults

Grove won't let a stray click wipe your work. There's no force push, discarding a file or dropping an unpushed commit always asks first, and anything that reaches beyond your machine asks too.

Keeps working while you don't

Switch to another project and this one keeps going — its agent and shell run on in the background even when you're not looking. Check in on one thing without pausing another, and come back to exactly the tab you left.

Why native?

Built for macOS.
Not ported to it.

  • ✓ Built to never freeze on you — no spinning beachballs, even with several agents running at once.
  • ✓ Feels like part of macOS, not a webpage in a window — matches your Dark Mode, your font size, your system, right out of the box.
  • ✓ Install with confidence — Apple has verified Grove is safe, so you won't hit a scary "unidentified developer" warning, even outside the App Store.
  • ✓ Finds your tools wherever you installed them — Homebrew, ~/.local/bin, ~/.bun/bin — even when you launch Grove from the Dock, not a terminal.
