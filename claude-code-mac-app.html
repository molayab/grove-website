Guide

Run Claude Code in a native Mac app

Grove for Mac · Updated November 2026

Short version: Grove gives Claude Code, and other CLI coding agents, a home in a native macOS window. The agent runs exactly as it does in Terminal, next to a real shell, your file tree and a GitHub-style diff of what it changed. All of it follows the git worktree you're working in.

Claude Code, unchanged

Claude Code is a terminal program, and Grove keeps it that way. It runs the real claude command in a real terminal (a PTY), in your project folder, with your own environment, configuration and login. Grove doesn't proxy your requests, add its own AI model, inject credentials or pass your code to the agent as arguments. You get the same Claude Code, with a better workspace around it.

Grove finds agents installed in the usual places, including ~/.local/bin, Homebrew and Bun, even when you open the app from the Dock rather than a terminal.

Any agent, chosen per project

Grove isn't tied to one vendor. It runs Claude Code, opencode, Codex, Gemini CLI and Aider. Each checkout remembers which agent you picked, and you can open several agent tabs side by side. Your tabs, their order and each tab's agent come back after a relaunch.

Review what the agent changed

The Changes tab lists every modified file with a GitHub-style diff and syntax highlighting. Files you've looked at are marked as viewed, and the mark clears if the agent changes them again. Click "+" on any line to leave a comment. Comments collect into a single review, and Send types the whole review into the agent's prompt so you can read it before pressing Return. Grove never submits it for you.

Prompts and commands you reuse

Save the prompts you keep retyping, and the shell commands you run every day, per project or in a shared library. Run them from the toolbar or the ⌘K palette. Templates fill in values like {{branch}}, {{date}} or your clipboard, and ask for anything else before running.

Parallel work with git worktrees

Give each agent its own branch in its own worktree. Switching worktrees in the sidebar moves the agent, shell, files, diff and git panel together, and each agent keeps running while you're looking at another one. See A git worktree app for Mac for how that works.

Built for the Mac

Grove is written in Swift and SwiftUI, not Electron. It follows your system's appearance, launches quickly, and is signed with a Developer ID and notarized by Apple. Closing the window doesn't stop anything: your agents and shells keep running until you quit.

Questions

Do I need a Claude subscription?

Grove doesn't include an AI model. You need Claude Code installed and your own Anthropic account, the same as in Terminal. What the agent sends is between you and its provider; Grove itself doesn't upload your repository.

Can I use it without Claude Code?

Yes. Use opencode, Codex, Gemini CLI or Aider instead, or just the shell, files and diff panes.

What does it cost?

There's a 7-day free trial. After that, a license is $9.99 one-time for one Mac, with every future update included. Grove needs macOS 26 or later.
