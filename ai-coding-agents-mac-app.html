A Mac app for AI coding agents

Grove for Mac · Updated November 2026

Short version: Coding agents like Claude Code, Codex and Gemini CLI live in the terminal, but the work around them doesn't: you also need a shell, your files, a diff of what changed and git. Grove is a native Mac app that puts all of that in one window, tied to the git worktree the agent is working in. You bring the agent; Grove doesn't add an AI of its own.

What an agent actually needs around it

An agent session is more than a chat. While it works you run the tests, read the files it touched, check the diff, and commit or throw away the result. In a plain terminal that means a few windows and a git client that don't know about each other, all pointed at the same folder by hand.

Grove keeps those pieces together. Each checkout gets an Agent tab, as many Shell tabs as you want, a Files tab with previews, a Changes tab with the diff, and a git panel in the sidebar. They all open in the same folder, so there's nothing to cd into and nothing to keep in sync.

Bring the agent you already use

Grove works with Claude Code, opencode, Codex, Gemini CLI and Aider out of the box. For anything else, point Grove at the executable in Settings and it shows up next to the others. Each checkout remembers which agent you picked.

The agent runs exactly as it would in Terminal: the real command in a real terminal (a PTY), with your own environment, configuration and login. Grove doesn't proxy requests, ship its own model, or pass your code to the agent. If you change agents next month, your workspace doesn't change with them. Run Claude Code in a native Mac app covers this in more detail.

Several agents at once, without collisions

Two agents editing the same checkout will trip over each other. The usual fix is a git worktree per task: a separate folder on its own branch, sharing one repository. Grove creates a worktree from any branch in a click, and switching worktrees in the sidebar moves the agent, shell, files, diff and git panel together.

Agents keep running when you look away. Switch to another worktree or project and the one you left keeps going in the background; come back and you're on the same tab. You can also open several agent tabs in one checkout. See A git worktree app for Mac for how worktrees work in Grove.

Review before you accept

The Changes tab updates live as the agent edits files, with a GitHub-style diff for each one. Comment on any line, and Grove gathers your comments into one review and types it into the agent's prompt. You read it and press Return yourself; Grove never submits it for you.

Safe defaults

Agents move fast, so the app around them shouldn't. Grove has no force push. Discarding a file or dropping an unpushed commit always asks first, and so does anything that reaches beyond your machine. Git actions use plain words: one Sync button instead of fetch, pull and push.

Native, not a web app

Grove is written in Swift and SwiftUI rather than Electron or a web UI. It follows your system's appearance, launches quickly, and is signed with a Developer ID and notarized by Apple. Closing the window doesn't stop your agents or shells; they run until you quit.

How it compares

A terminal plus a git client. Free, and it works. Grove replaces the juggling: the agent, shell, files and diff are already in the same checkout, and switching tasks is one click.

AI terminals and AI editors. These usually come with their own assistant or model. Grove isn't an editor and doesn't include an AI; it gives the CLI agent you chose a better place to run. Keep your editor for editing.

Other agent workspace apps. Many are built on web technology and sold as a subscription. Grove is native, and it's a one-time purchase.

Questions

Does Grove include an AI model?

No. You install the agent and sign in with your own account, the same as in Terminal. What the agent sends is between you and its provider; Grove itself doesn't upload your repository.

Which agents does it support?

Claude Code, opencode, Codex, Gemini CLI and Aider are built in, and you can add any other command-line agent by choosing its executable.

What does it cost?

There's a 7-day free trial. After that, a license is $9.99 one-time for one Mac, with every future update included. Grove needs macOS 26 or later.
