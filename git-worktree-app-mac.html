A git worktree app for Mac that moves your whole workspace

Grove for Mac · Updated November 2026

Short version: Grove is a native macOS app that lists every git worktree in your repository and lets you switch between them with one click. When you switch, your AI coding agent, shell, file tree, diff and git panel all move to that checkout together, so you never end up committing on one branch while reviewing another.

Why developers use git worktrees

git worktree lets one repository have several working directories at once, each on its own branch. You can fix a bug on main while a feature branch keeps building, review a pull request without stashing your work, or give each AI coding agent its own branch so two agents never edit the same files.

The catch is everything around the command. After git worktree add you still have to cd into the new folder, open another terminal tab, point your editor and diff tool at it, and restart your agent there. Then you have to remember which window belongs to which branch.

How Grove manages multiple worktrees

  • Every worktree in one list. The Worktrees panel in the sidebar shows all the worktrees of the selected repository, including the ones you created on the command line.
  • Create one from a branch. Pick an existing branch or type a new one. Grove creates a standard git worktree under a folder you choose in Settings, laid out as <root>/<repo>/<branch>, so you never have to think about paths.
  • One click switches everything. Selecting a worktree points the whole app at that checkout: the Agent and Shell panes, the file tree, the Changes diff, and the git panel for branch, commit, pull and push.
  • Each worktree keeps its own state. The agent you picked, your terminal tabs, pinned websites and any pending diff-review comments are remembered per checkout and come back after a relaunch.
  • Removal is confirmed. Removing a worktree deletes a checkout from disk, so Grove asks first and tells you if you'd lose unsent review comments.

Parallel branches with AI coding agents

Worktrees and coding agents fit together well: run Claude Code on a feature branch in one worktree and Codex on a bug fix in another, each in its own isolated checkout. The terminal session for each checkout keeps running when you switch away, so an agent in the middle of a task isn't interrupted. When it's done, open the Changes tab for that worktree and review exactly what it changed.

More on the agent side in Run Claude Code in a native Mac app.

Real git, no lock-in

Grove runs the git already installed on your Mac. The worktrees it creates are ordinary git worktrees: git worktree list shows them, and you can keep using the command line next to Grove. Nothing is stored in a proprietary format, and Grove doesn't force-push or delete branches.

A native Mac app, not a web wrapper

Grove is built in Swift and SwiftUI rather than Electron. It follows your system's appearance, opens quickly, and keeps your agents and shells running even if you close the window.

Questions

Does Grove work with worktrees I already have?

Yes. It reads the repository's worktree list, so existing worktrees show up as soon as you add the repository.

Do I have to stop using the git CLI?

No. Grove uses standard git under the hood, so the command line, other git clients and Grove all see the same state.
